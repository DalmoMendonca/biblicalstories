## Batch pipeline
- Acquire immutable raw sources, record exact URL, edition, access/license, SHA256, page or text ranges. Record failed access separately. No bypass of access controls.
- Parse TEI/ALTO/layout blocks; use the catalogue's 52+52 sequence and heading/title matching, not evenly spaced character interpolation. For ambiguous boundaries, compare original scans. Maintain a page-level manifest and checkpoint each completed story.
- Process all stories in bounded independent batches, with retries on transient acquisition failures, caching and resumable outputs. Compare every extracted story against its source; OCR is the last resort on missing text, not the primary process.
- Write structured chapter records keyed by stable id and language with narrative, numbered questions, teachings (question and answer pairs), reflection lines, optional Latin lines, edition, source page references, source kind, review state. Preserve original wording and numbering; record orthographic normalization explicitly. Do not use already archived corrupted translations as inputs.
- Review independently: compare first/last sentence and every question, teaching and verse to the witness; compare expected numbering with actual counts. Flag uncertain characters and unresolved source gaps. Record completeness and fidelity separately, at section level. Do not claim independent proofreading unless performed.
- Build a coverage report with 104 rows and 12 mandatory columns; distinguish acquired, extracted, source-compared, missing, and rejected. No false-positive text_complete label for arbitrary strings, machine translations, or narrative-only versions.
- Commit only factual corpus data and reader integration. Validate that every published record maps to the correct title, all four sections render, navigation works for all 104 IDs, source links work, and production deploy uses the intended commit. Preserve previously valid content while incomplete work remains clearly labeled.

## Release gate
104/104 in EACH language, all 1,248 required sections, no empty/duplicate/mislabeled content, no unresolved chapter boundaries or silently replaced text, and explicit edition-specific provenance. New English translations from source-compared German are authorized as a fallback only, distinctly identified; no new Russian translations. The release gate cannot be guaranteed while the source is unacquired or an eligible edition is unconfirmed.

Do not make another sequence of partial narrative-only edits and call the project complete. Use a corpus-level execution environment for large source downloads, layout parsing, validation, and publication; track exact counts and reproducible commands.
