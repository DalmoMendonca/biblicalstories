# Complete trilingual corpus recovery

Acceptance target: 104 stories × 3 languages × 4 mandatory sections (1,248 nonempty, source-grounded sections), plus Latin poetry where printed. Preserve the numbered narrative/questions correspondence, moral teaching question/answer pairs and every verse line. Keep historical illustrations unchanged.

## Source priority
1. German: Giessen 1768 (Heidelberg) is the primary illustrated witness; use library OCR instead of re-running OCR wherever available. Cross-check against Tübingen 1773 TEI (https://opendigi.ub.uni-tuebingen.de/opendigi/Gi1824ab; DOI 10.20345/digitue.12151) and Zürich ca. 1775 ALTO/plain text (https://doi.org/10.3931/e-rara-85573), already archived in public/data/german-ocr.txt. Never silently substitute a different edition. Extract existing per-page layout text first; map actual printed start/end positions, including the opening of the next story's page when the preceding reflection or Latin verse continues there.
2. Russian: prioritize the actual Bogorodsky translation, 1798 and subsequent printings, including the 1825 Old and New Testament witnesses (https://kp.rusneb.ru/item/material/5fcf8bb3991f3b91423439b5 and https://kp.rusneb.ru/item/material/sto-chetyre-svyashchennyya-istorii-pyatdesyat-dve-svyashchennyya-istorii-iz-novago-zaveta--ch2). Try library-provided text/ALTO/PDF text layer before page recognition. The 1812 RSL edition explicitly names all four components but also names Johann Fleck and editorial revision; inspect title page and all chapter order before accepting (https://search.rsl.ru/ru/record/01008044637). Modern copyrighted adaptations are not a publication source.
3. English: 1765 Hamburg is a narrative-only partial witness (already archived; preserve independently). Philadelphia 1838 and related adaptations require section-by-section fidelity checks: scholarly research documents replacements of Hübner's applications/reflections (https://www.academia.edu/110072389/Forty_six_Select_Scripture_Narratives_from_the_Old_Testament_Vol_1). Do not count a paraphrase or replacement as original. The owner explicitly rejects newly generated translations, including otherwise faithful ones. Existing historical translations and independently published transcriptions only; continue discovery rather than inventing replacements. Same rule for Russian gaps.

## Batch pipeline
- Acquire immutable raw sources, record exact URL, edition, access/license, SHA256, page or text ranges. Record failed access separately. No bypass of access controls.
- Parse TEI/ALTO/layout blocks; use the catalogue's 52+52 sequence and heading/title matching, not evenly spaced character interpolation. For ambiguous boundaries, compare original scans. Maintain a page-level manifest and checkpoint each completed story.
- Process all stories in bounded independent batches, with retries on transient acquisition failures, caching and resumable outputs. Compare every extracted story against its source; OCR is the last resort on missing text, not the primary process.
- Write structured chapter records keyed by stable id and language with narrative, numbered questions, teachings (question and answer pairs), reflection lines, optional Latin lines, edition, source page references, source kind, review state. Preserve original wording and numbering; record orthographic normalization explicitly. Do not use already archived corrupted translations as inputs.
- Review independently: compare first/last sentence and every question, teaching and verse to the witness; compare expected numbering with actual counts. Flag uncertain characters and unresolved source gaps. Record completeness and fidelity separately, at section level. Do not claim independent proofreading unless performed.
- Build a coverage report with 104 rows and 12 mandatory columns; distinguish acquired, extracted, source-compared, missing, and rejected. No false-positive text_complete label for arbitrary strings, machine translations, or narrative-only versions.
- Commit only factual corpus data and reader integration. Validate that every published record maps to the correct title, all four sections render, navigation works for all 104 IDs, source links work, and production deploy uses the intended commit. Preserve previously valid content while incomplete work remains clearly labeled.

## Release gate
104/104 in EACH language, all 1,248 required sections, no empty/duplicate/mislabeled content, no unresolved chapter boundaries or silently replaced text, and explicit edition-specific provenance. No new translations are authorized. Do not fill gaps with newly written translations, even if labeled. The release gate cannot be guaranteed while the source is unacquired or an eligible edition is unconfirmed.

Do not make another sequence of partial narrative-only edits and call the project complete. Use a corpus-level execution environment for large source downloads, layout parsing, validation, and publication; track exact counts and reproducible commands.
